# Security policy

## Supported versions

Only the current `main` branch is maintained. This project is experimental and
does not promise compatibility with every Solarpunk build.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** option on the repository's Security
tab to submit a private report. Include the affected commit, reproduction
steps, impact, and any proposed mitigation. Do not include proprietary game
files, credentials, or personal data.

Please use public issues for ordinary crashes, compatibility failures, and
feature bugs. A game update that invalidates a schema is not a security
vulnerability; the expected behavior is for affected features to fail closed.
